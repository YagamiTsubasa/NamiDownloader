# 纳米素材下载器 0.1（开发测试版）

这是 Python 桌面应用源码，包含中文界面、自定义图标及 Mac 打包脚本。

![纳米素材下载器图标](assets/icon.png)

本仓库不包含虚拟环境、下载工具二进制和构建产物。
第一版面向 Apple 芯片 Mac，支持接入 YouTube 和 B站；实际下载能力须在你的网络和 Mac 上验收。

## 已实现

- 中文图形界面；批量粘贴链接或分享文案；顺序下载；最高 720/1080/2160p。
- 输出 MP4 封装，保留源编码，不强制转码成 H.264。某些源编码无法装入 MP4 时任务可能失败。
- 自动编号：例如 `0096_视频ID.mp4`。同编号、同 ID 的已存在文件不覆盖。
- 进度、失败详情、停止队列、重试失败/停止任务。队列仅保存在当前会话。
- 可选 Chrome/Firefox 登录状态读取，每次新队列明确授权；默认关闭。
- 可选代理地址。留空使用引擎默认网络设置，不保证自动识别 macOS 所有系统代理配置。
- 下载引擎使用内置路径，不依赖同事机器的 PATH、Homebrew 或 Python。
- 抖音、TikTok、小红书预留入口，目前明确提示未接入。

## 仅打包者操作一次，同事不用操作

1. 使用 Apple 芯片 Mac 原生终端。请先确认 macOS 版本，优先在团队最旧的可用系统上构建。
2. 打包机需要 Homebrew（https://brew.sh）。如果已经安装，不要重复安装。
3. 把整个工程解压，终端输入 `bash `（后有空格），把 `build_mac.command` 拖进终端，再按回车。
4. 脚本安装构建依赖：Python 3.12、FFmpeg、Deno；创建独立 `.build-venv`；安装固定版本 PySide6/PyInstaller。
5. 下载官方 yt-dlp macOS 独立程序，用同一版本发布的 SHA256 清单校验。它内含 Python 和 EJS 相关组件。
6. PyInstaller 收集 GUI、解释器、FFmpeg、Deno 及关联动态库；构建脚本检查外部动态库路径。
7. 成功后 `dist/NamiDownloader.app` 和 `dist/NamiDownloader-arm64.dmg` 可供验收。

首次构建需要联网下载组件，可能较慢。GitHub、PyPI、Homebrew 无法访问时构建会停止并输出错误；不要把不完整产物分发。
打包依赖只装在你的机器上，最终用户不用安装。
构建脚本不会关闭 Gatekeeper 或删除系统安全标记。

## 发给同事前必须验收

已在 Apple Silicon / macOS 13.7.4 上配置并由使用者确认源码界面可启动。Mac 应用打包、签名校验和外部依赖路径检查通过，6 项核心逻辑测试通过。打包版启动、真实网站下载和其他 Mac 兼容性仍需验收。

- 在打包机执行构建，确认产物可启动。
- 再在一台没有 Homebrew/Python/FFmpeg 的 Mac 测试，尤其是团队最低 macOS 版本。
- 测 YouTube 普通视频、Shorts，B站普通视频和 b23.tv 短链接。
- 确认每个平台下载的视频有声音，时长正常，目标标注平台能解码。
- 测登录授权、网络失败、中文/空格目录、重名文件、停止下载和重试。
- Homebrew 工具的最低系统版本可能比 GUI 更高：arm64 相同不等于 macOS 版本兼容。
- 分发前核对构建依赖的许可与对应源码提供要求；见 THIRD_PARTY.md。

这是本地 ad-hoc 签名测试包，没有 Developer ID 公证。接收方 macOS 可能拦截：仅对确认来源的应用，通过系统设置的“隐私与安全性”按系统提示允许打开。公司设备策略可能禁止这种方式。不要全局关闭系统安全保护。

## 使用

粘贴链接 → 选择目录/清晰度/起始编号 → 开始下载。
想使用登录状态时，在对应浏览器正常登录网站，再选择该浏览器；系统可能要求钥匙串授权。
需要修改代理/登录/清晰度时，停止队列，修改设置，再点“开始下载”建立新队列。
“重试失败 / 已停止”沿用原任务参数和编号，不更改已完成任务。
编号不会跨会话自动递增；新批次请调整起始编号，避免重复目标路径被跳过。
第一版不批量抓取频道、播放列表；B站多P请给具体分P链接并核验结果。
保存的视频用于你有权下载和使用的素材。

## 维护与扩展

- `core.py`：平台注册表、URL 校验、下载参数、错误归类与脱敏。
- `app.py`：界面、进程、队列。实际命令通过参数数组调用，不使用 shell 拼接用户输入。
- `prepare_vendor.py`：构建期准备组件、校验 yt-dlp、记录工具版本。
- `audit_bundle.py`：构建期检查外部动态库依赖。
- `build_mac.command`：生成 app 和 DMG。
- `tests`：逻辑测试和模拟下载进程集成测试。

`PLATFORMS` 的 disabled 项只是预留注册位，不能简单改为 True 就宣称支持；应为新平台实现独立解析适配、测试后再开放。
yt-dlp 更新：在你的构建机重新打包并分发。没有在同事电脑后台下载安装代码。
可用环境变量 NAMI_YTDLP_TAG 指定已有发布标签复现下载引擎版本。
`vendor/build-info.json` 记录构建时工具版本；Homebrew 依赖没有完全锁版本，因此当前不是位级可复现构建。

## 开发测试

在安装 PySide6 的 Python 环境中：

```bash
python3 -m unittest discover -s tests -v
python3 app.py
```

源码启动前须先在 Mac 执行 `prepare_vendor.py` 准备运行组件，或者运行完整构建脚本。
`tests/test_gui.py` 使用模拟下载器，不访问视频网站，不能替代真实下载验收。
